Verezza es una tienda e-commerce headless desarrollada desde cero. El objetivo fue implementar las funcionalidades core de un comercio electrónico de producción, con un frontend desacoplado de Shopify y un stack alineado a escenarios reales: React, TypeScript, Remix y GraphQL.

## Headless con Shopify Storefront API

Conecté el frontend a Shopify mediante Storefront API en GraphQL, consumiendo productos, colecciones y variantes. Sobre esa integración implementé autenticación, catálogo, carrito, wishlist y checkout, con manejo de estados y errores en Remix.

## Lo que implementé

- Funcionalidades core de e-commerce: autenticación, catálogo con filtros dinámicos, carrito persistente, wishlist y checkout integrado con Shopify.
- Interfaz responsive mobile-first, con soporte multiidioma (español/inglés) y multi-moneda (COP/USD/EUR).
- Integración con Shopify Storefront API vía GraphQL.
- Optimización de rendimiento con Server-Side Rendering (SSR), lazy loading y caché inteligente.
- Content Security Policy para una experiencia de usuario fluida y segura.
